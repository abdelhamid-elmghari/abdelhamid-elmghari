## `01 / PROFILE`

I'm Abdelhamid Elmghari, an AI and Software Engineering student from
Morocco.

I build and explore software around **AI agents, retrieval-augmented
generation (RAG), machine learning, and workflow automation**. My focus
is on understanding how models, tools, data, and backend services work
together to create useful applications.

Currently exploring agent memory, tool orchestration, retrieval quality,
and practical AI system design.
